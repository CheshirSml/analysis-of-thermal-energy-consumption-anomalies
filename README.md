Этот проект направлен на автоматическое обнаружение аномалий в данных о потреблении тепловой энергии с использованием методов машинного обучения и статистического анализа. ## 📖 Описание проекта

Потребление тепловой энергии в жилых и коммерческих зданиях обычно следует предсказуемым паттернам, зависящим от времени суток, дня недели и погодных условий. Однако отклонения от этих паттернов могут сигнализировать о проблемах:  
- технические неисправности (утечки в системе отопления),  
- ошибки измерений,  
- несанкционированное подключение,  
- резкие изменения в режиме потребления.

Данный проект реализует конвейер обработки данных и обнаружения аномалий на основе временных рядов, включая:
- предварительную обработку и очистку данных,
- извлечение признаков (в т.ч. с учётом внешних факторов, например, температуры),
- применение алгоритмов обнаружения аномалий,
- визуализацию результатов через интерактивный веб-интерфейс.

## ⚙️ Основные возможности

- Загрузка и валидация данных по потреблению тепловой энергии.
- Автоматическая очистка данных от пропусков и выбросов.
- Учёт внешних факторов (например, температуры наружного воздуха).
- Обнаружение точечных и контекстуальных аномалий.
- Интерактивный веб-интерфейс на основе **Streamlit** для визуализации и анализа.
- Модульность: легко подключить новые алгоритмы или источники данных.

## 🛠 Технологии и зависимости

- **Язык**: Python 3.8+
- **Основные библиотеки**:
  - `pandas`, `numpy` — обработка данных
  - `scikit-learn` — машинное обучение и обнаружение аномалий
  - `streamlit` — интерактивный веб-интерфейс
  - `matplotlib`, `seaborn`, `plotly` — визуализация

Все необходимые зависимости перечислены в файле [`requirements.txt`](requirements.txt).

Установите их командой:

```bash
pip install -r requirements.txt
```

## ▶️ Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/CheshirSml/analysis-of-thermal-energy-consumption-anomalies.git
cd analysis-of-thermal-energy-consumption-anomalies
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите веб-приложение:

```bash
streamlit run app/app.py
```

После запуска откроется локальный сервер (обычно `http://localhost:8501`), где вы сможете:
- просмотреть загруженные данные,
- настроить параметры обнаружения аномалий,
- визуализировать результаты.

> 💡 Приложение использует предварительно обработанный файл `data/df.csv`. Если вы хотите использовать свои данные — замените этот файл и при необходимости адаптируйте код в `app/app.py`.
